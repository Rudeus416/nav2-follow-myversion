# 手绘走廊地图

`corridor.yaml` 是供 Nav2 map_server 加载的地图配置，`corridor.pgm` 是地图图片。没有地砖分格线。

- 净通行区域：宽 2.1 米、长 8.4 米（原 4.2 米的两倍）；分辨率 0.05 米/像素。
- 图片 44×168 像素：42 列空地，两侧各增加一列黑色墙体；墙体不占用净宽。
- 下方和上方暂按开放处理。图外环境未建模，开放端不代表图外也可规划。
- 地砖布局已按原示意图左右镜像：从左至右为 0.3 米半块砖、三块 0.6 米完整砖。小车仍对应最下排三块完整砖中间那块；不控制实体小车移动。导航图不绘制格线，两侧墙对称，因此镜像前后像素相同。
- map 坐标：右为 +X，上为 +Y；通道内部左下角为 (0, 0)。
- 初始位置按最下排中间完整砖的中心估算：x=1.2 米、y=0.3 米，yaw=π/2（朝上）；对应四元数 z=0.70710678、w=0.70710678。
- 假设完整地砖为 0.6×0.6 米、小车 base_link 位于该砖中心，需实地核对。

新地图已原位替换 `corridor.pgm`，`corridor.yaml` 路径和原点不变。新增长度位于地图上方（+Y），旧地图下半段和起点保持不变。`nav2/follow.launch.py` 的地图/叠加模式默认通过 map_server 加载此文件，并沿用固定 map → odom 起点对齐。停车后重启服务并刷新网页生效；若设置了 `NAV2_MAP_FILE`，则实际加载该变量指定的地图。

本次仅延长地图，不改变真实场地、起点余量或碰撞规则；此前起点车身压住地图后边界的问题仍需单独处理。
